# Analysis artifacts for "Latent-State Auditing for Tool-Using Language Agents"

Every table cell and quoted number in the paper is generated by the scripts in
this directory from the run data in `../runs/` and `../data/expanded/`, and
verified end-to-end by `verify_paper.py` (which machine-diffs the LaTeX source
against these JSONs and exits nonzero on any mismatch).

Scripts (all take `--run-dir` / explicit inputs; folds seed 13, 5-fold,
1,000-resample bootstrap CIs via the package's own `bootstrap_metric_ci`):

- `stratified_analysis.py` — exposure-vs-commitment stratification, per-step
  AUROCs, early-flag counts.
- `commitment_probes.py` — commitment-contrast monitors (centroid, logistic,
  NLA-text NB, visible-text NB), label-stratified + user-task-grouped folds.
- `transcript_and_leakage_controls.py` — trained-transcript baselines,
  cross-injection-goal transfer, identity-prior ceiling, NB features.
- `reviewer_response_analyses.py` — per-step commitment, TF-IDF text baseline
  (+ on NLA text), grouped-seed stats, user-task cluster bootstrap.
- `cross_transfer.py` — train-on-one-run / test-on-another transfer.
- `provenance_ablation.py`, `transfer_cis.py` — replay-grid ablations and CIs.
- `judge_baseline.py` — AUROCs for the zero-shot LLM-judge outputs
  (`../data/expanded/judge_*.jsonl`, produced by `../scripts/run_judge.py`).

JSON artifacts are the exact outputs behind the paper's tables:
T3_* (replay grid), EXP_* (primary 280-case workspace grid),
MISTRAL_* (second-model replication), `*_pre-tiefix.json` preserve the
summaries computed before the average-precision tie-handling fix in
`latent_agent_auditing/eval/metrics.py` (see that commit's diff).

Run data in `../runs/<name>/`: manifests, case scores, per-run summaries, and
gzip-compressed `audits.jsonl.gz` containing all captured activations and
(where applicable) NLA verbalizations. `../scripts/` holds the exact pod
pipelines that produced the exports and audits.
